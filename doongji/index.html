직수행 건물별 영업이익
건물 탭에서 수행방식을 '직수행'으로 지정한 건물만 나와요
지점 건물명 매출 (건물주 청구) 직수행 견적 실제 수행비 영업이익 이익률 견적 대비
· 영업이익 = 매출 − 실제 수행비 · 견적 대비 = 직수행 견적 − 실제 수행비 (＋면 견적보다 적게 씀, −면 초과)
· 합계와 이익률은 실제 수행비를 입력한 건물만 계산해요 · 매출·견적은 건물 탭의 수정 화면에서 바꿀 수 있어요
건물별 영업이익 (월)
행을 누르면 청구·외주 수행비를 수정할 수 있어요
지점 건물명 / 업체 수행방식 건물주 청구 외주 수행비 둥지 견적비 영업이익 이익률
· 영업이익 = 건물주 청구 − 수행원가 · 수행원가는 외주 건물은 외주 수행비, 직수행 건물은 둥지 견적비(미화팀 견적)
· 이익률 30% 이상 양호 / 10% 이상 주의 / 그 미만 위험 · 둥지 견적비는 미화팀이 입력해요

👥 권한 관리

· 관리자·미화팀: 모든 탭과 금액, 수정 가능
· 영업팀: 건물 등록·청구/외주 수행비 수정, 영업이익(청구 − 외주 수행비·둥지 견적비) 보기 · 둥지 인건비·실제 수행비는 못 봐요
· 승인 대기: 아무것도 못 봐요
· 새 직원 계정은 Supabase → Authentication → Users → Add user에서 만든 뒤, 여기서 권한을 지정해주세요.
